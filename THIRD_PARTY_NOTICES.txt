Third-party notices for simple-ca
=================================

This file lists the licenses of the Go modules simple-ca depends on
(go.mod). It covers the whole module graph, so a module that `go version -m`
prints for a built binary is always found here, and where a build links only
part of a module the package is named on the entry. The project itself is
licensed under GPL-3.0-only; see LICENSE.txt.

Every entry is keyed by the module path that `go version -m` and
`go list -m all` print, so a dependency found in a built binary can be
cross-checked against this file by name.

Where a module's files are covered by more than one license, the entry names
every license that applies to what is linked, not only the first one its
license file mentions. Modules under the Apache-2.0 license that ship a NOTICE
file have that notice reproduced here, as section 4d of the license requires.

Full license texts for each dependency are available at the LicenseURL listed
below (standard Go module practice).
